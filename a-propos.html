(01) — Pourquoi ce site

Un portfolio qui sert de support à l'épreuve E5.

Ce site rassemble ce qui est présenté à l'épreuve E5 du BTS SIO option SLAM : le parcours, le stage de première année chez ZENG Expertise, les projets, la veille technologique et les certifications.

Il s'adresse d'abord au jury du BTS, puis aux entreprises qui proposent un stage ou une alternance, puis aux écoles post-BTS.

Une adresse unique. L'adresse du site figure en en-tête du tableau de synthèse de l'épreuve : c'est par elle que le jury accède à l'ensemble des preuves.

(02) — Sous le capot

Trois langages, zéro dépendance.

Langages

Écrit directement

HTML pour la structure, CSS pour la mise en forme, JavaScript pour les interactions : menu, formulaire.

HTMLCSSJavaScript

Dépendances

Aucune

Pas de framework, pas de générateur de site, pas de paquet npm. Une seule feuille de style, un seul script. La seule ressource externe est la police de caractères, chargée depuis Google Fonts.

Hébergement

GitHub Pages

Le site est servi à partir d'un dépôt public. Chaque modification poussée sur GitHub est publiée en une à deux minutes.

(03) — Deux scripts d'aide

Écrire une fois, vérifier avant de publier.

Deux petits scripts Python servent à construire le site. Ils ne sont jamais exécutés dans le navigateur d'un visiteur.

_outils/propager.py

Un menu, écrit une seule fois

Le menu et le pied de page sont rédigés dans la page d'accueil. Le script les recopie dans toutes les autres pages et marque la page en cours dans le menu. Sans lui, chaque changement de menu demanderait de modifier tous les fichiers à la main.

_outils/verifier.py

Un contrôle avant chaque publication

Liens cassés, images sans texte alternatif, balises mal fermées, titre principal unique, identifiants en double, images trop lourdes. Il compte aussi les champs qui restent à compléter.

(04) — Accessibilité

Lisible par tous, au clavier comme à la souris.

  • Lien d'évitement — « Aller au contenu » permet de passer le menu en navigation au clavier.
  • Structure sémantique — en-tête, navigation, contenu principal et pied de page sont balisés comme tels, et le menu signale la page en cours.
  • Textes alternatifs — chaque image en possède un, ce que vérifie le script de contrôle.
  • Focus visible — l'élément atteint au clavier est entouré.
  • Contrastes — le texte principal bleu atteint 8,5 : 1 sur fond clair et le texte secondaire 7,6 : 1. La couleur vive, trop pâle pour du texte (4,1 : 1), est réservée aux aplats.
