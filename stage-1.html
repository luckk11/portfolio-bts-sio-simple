Le projet

L'objectif : développer un outil capable d'analyser des données liées aux cryptomonnaies à partir d'informations historiques et d'articles de presse, pour en faire à terme une offre proposée aux clients du cabinet. Le cœur du système est une architecture RAG — Retrieval-Augmented Generation : plutôt que d'interroger un modèle de langage à l'aveugle, on récupère d'abord le contexte pertinent dans une base vectorielle, puis on le fournit au modèle pour produire une analyse ancrée dans des sources réelles.

Le projet s'est poursuivi au-delà des cinq semaines de stage : le chantier était trop lourd pour tenir dans la durée impartie. En savoir plus

Missions réalisées

  1. Exploration des données et conception du schéma SQL. Un script Python a été développé pour parcourir un échantillon des fichiers JSON contenant les articles et recenser l'ensemble des clés présentes.
  2. Développement du pipeline d'extraction ETL. Automatisation de la chaîne extraction — transformation — chargement : récupération des données de marché et des articles, nettoyage, mise au format, puis insertion en base.
  3. Intégration de l'IA : génération des embeddings. Chaque texte est converti en vecteur numérique par une API d'intelligence artificielle, puis stocké avec pgvector.
  4. Architecture et optimisation des index SQL. Travail sur la structure des index pour réduire les temps de réponse des requêtes d'exploitation, en particulier sur les recherches vectorielles.
  5. Interface de démonstration en ligne de commande. Une interface CLI pour manipuler le moteur sans passer par le code : indispensable pour démontrer le fonctionnement du prototype et le faire tester par quelqu'un d'autre que son développeur.
  6. Moteur de recherche hybride. Aboutissement du projet : combiner la recherche classique par mots-clés et la recherche sémantique par vecteurs, afin de ne pas perdre les correspondances exactes tout en captant les formulations différentes.

Bilan

Le principal apport n'est pas une technologie en particulier, mais un standard d'exigence. Qualité du code, optimisation des performances, respect des bonnes pratiques, documentation systématique : autant de réflexes qu'un exercice scolaire n'impose jamais vraiment, et qu'une structure professionnelle rend obligatoires dès la première ligne écrite.

Le second apport est une confirmation. L'objectif professionnel — Data Analyst puis Data Scientist en intelligence artificielle — reposait avant ce stage sur une intuition. Il repose désormais sur une expérience concrète du métier.
